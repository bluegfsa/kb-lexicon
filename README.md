# kb-lexicon

双译键盘派生中英词库（独立数据文件），以 **CC BY-SA 4.0** 提供，方便他人获取与复用同版本数据。

- `data/zh2en.txt` — 中→英（键<TAB>译文，按 key 升序）
- `data/en2zh.txt` — 英→中（键<TAB>译文，按 key 升序）
- `SHA256SUMS` — 数据校验
- `NOTICE` — 三源署名与修改说明
- `LICENSE` — CC BY-SA 4.0 全文
- `tools/` — 生成脚本（MIT）

版本：每次随 App 出包打 tag（如 `v1.69-lexicon`），数据与 App 包内同版本同 SHA。
